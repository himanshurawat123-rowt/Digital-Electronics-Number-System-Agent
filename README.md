## 📌 Overview
This project is an **AI-Powered Conversational Agent** designed for multi-base number system conversions (Binary, Octal, Decimal, Hexadecimal, and Base 2–36). It automatically parses natural language queries, performs strict radix validation, detects invalid digits, and generates step-by-step mathematical proofs.

## 🚀 Key Features
* **Conversational Interface:** Accepts commands like *"Convert 101101 from binary to hexadecimal"* or *"Convert 255 to binary"*.
* **Radix Validation Engine:** Detects invalid characters per base (e.g., digit `2` in Base-2, character `Z` in Base-16) with clear error protocols.
* **Step-by-Step Mathematical Derivations:** Shows full positional expansion ($d_i \times b^i$) and successive division remainder tables.
* **Multi-Base Support:** Seamless conversions across Base-2, Base-8, Base-10, Base-16, and arbitrary radices (2–36).
* **Voice & Manual Mode:** Real-time microphone voice input and structured manual conversion form.
