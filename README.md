## 📌 Overview
This project is an **AI-Powered Conversational Agent** that performs multi-base number system conversions (Binary, Octal, Decimal, Hexadecimal). It automatically parses natural language user queries, validates digit rules for the specified base, and outputs step-by-step mathematical reasoning.

## 🚀 Key Features
- **Conversational Interface:** Accepts inputs like *"Convert 101101 to decimal"* or *"Is 10201 a valid binary?"*
- **Validation Engine:** Detects invalid digits for a given radix (e.g., digit `2` in Base-2).
- **Step-by-Step Explanation:** Shows clear mathematical steps for both Base $X \rightarrow \text{Decimal}$ and $\text{Decimal} \rightarrow \text{Base } Y$.
- **Multi-Base Support:** Binary (2), Octal (8), Decimal (10), Hexadecimal (16).
